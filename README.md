# 🎯 CareerCompass AI

### Discover. Assess. Achieve.

CareerCompass AI is an AI-powered career guidance platform developed to help students discover career paths based on their personality, interests, technical skills, strengths, and aptitude. Instead of providing generic advice, the platform generates personalized career recommendations using Google's Gemini AI.

# 📌 Problem Statement

Many students are uncertain about choosing the right career due to limited access to personalized guidance. Traditional career counseling is often expensive, inaccessible, or provides generalized recommendations that do not reflect an individual's unique strengths and aspirations.

CareerCompass AI addresses this challenge by providing AI-driven, personalized career guidance to help students make informed career decisions.

---

# 💡 Solution Description

CareerCompass AI analyzes a student's complete profile, including:

- Personal Details
- Interests
- Technical Skills
- Strengths
- Areas for Improvement
- Aptitude Assessment (19 Questions)
- Descriptive Self-Assessment

Using Google's Gemini AI, the system evaluates the complete profile and generates a comprehensive career report containing:

- Personality Analysis
- Major Strengths
- Areas for Improvement
- Top Career Recommendations
- Career Roadmap
- Personalized Learning Resources
- Scholarship Recommendations
- Confidence Score
- Overall Career Summary
- Downloadable PDF Report

The platform aims to make career guidance accessible, personalized, and easy to understand for every student.

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/pallavitalawar25-cmd/CareerCompassAI.git
```

Move into the project folder

```bash
cd CareerCompassAI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open the browser

```
http://127.0.0.1:5000
```
